## Safe reproductions retained

`node project-notes/evidence/security-probes.mjs` transpiles current source and uses only mock asset/socket/fetch IO. Expected upstream output: nine global executions, accepted private destinations, and null-batch TypeError. Run from repository root after npm ci. It is a diagnostic probe, not a fixed-regression test; update expectations only when corresponding Phase 1 regressions are added. No real credential storage is read.

## Exposure policy

Local source/fixture work can continue. Anonymous spectating executes remote server gamedata and is not isolated fixture work; Phase 0 used a bundled public server without entering credentials. The development service binds loopback. Before account-bearing/public use, verify loader isolation, proxy destination/resource controls and secure transport. Before distribution, resolve corresponding-source and exact asset provenance. These are concrete source-backed gates, not a claim that any official server is hostile or that a deployed exploit occurred.
