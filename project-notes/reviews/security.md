# Independent security, licensing, and integration assessment

Date: 2026-11-11. Reviewer: security subagent. Revision: `b65fc15ca1b58969cb061a7749db8cbdb92b8f4d`. Read-only investigation; no production code changes, installations, credentials, or public-server attack tests. Safe reproductions used transpiled upstream modules, in-memory fixtures, and mock fetch/socket implementations. Probe script: `/private/tmp/dcss-security-probes.mjs`; command `node /private/tmp/dcss-security-probes.mjs` exited 0.

## Summary and release gates

A full Orbrun fork is reasonable, but its current trust boundary is unsuitable for arbitrary custom servers sharing an origin with saved accounts. Fix gamedata execution isolation and proxy destination restrictions before public deployment or using valuable credentials with untrusted servers. These issues do not block local read-only investigation, anonymous trusted-server baseline checks, or offline fixture work. Keep development service loopback-only. No evidence was collected of an actual account compromise, deployed SSRF exploit, or hostile official server.

## Existing protective behavior worth retaining

- Password is sent for login and not intentionally saved. Account token rotation/expiry and logout deletion exist (`servers.ts:275-309`, `session.ts:136-144,316-336`). LocalStorage tokens still make same-origin script execution consequential; token storage alone is not proof of a bug.
- Chat HTML is rebuilt from escaped text and span classes (`apps/orbrun/src/chat.ts:402-418`), with linkification restricted to HTTP(S) and noopener/noreferrer (`:421-442`). Do not mislabel every innerHTML use as XSS.
- Socket generation guards reject late events; queue clears on close; malformed JSON diagnostics and handler catches exist (`connection.ts:91-159`). Gamedata fetches support abort and dispose failed atlas loads (`gamedata/index.ts:517-534`), and Session has progress-stall timeout. Risks above describe missing bounds, not absence of all error handling.
- Proxy blocks traversal and unlisted gamedata filenames; HTTPS only and no userinfo mitigate some attacks. Host validation and redirect handling remain incomplete.

## Supply-chain triage details

The audit is for development tooling and transitive nodes as well as direct packages; duplicate advisory propagation explains why counts are package nodes, not distinct exploits. Root has all test/build/deploy tools in devDependencies; Three.js is the renderer runtime dependency. Audit recommends a major Vitest upgrade (5.1.0), so treat that as a migration requiring compatibility testing. Vite/happy-dom/Wrangler and transitive fixes are reported available; inspect exact installed/fixed versions rather than assuming broad version ranges are enough. Audit metadata is evidence, not proof the associated vulnerable methods are called by this app.

Representative audit references: [Vitest mock registration](https://github.com/advisories/GHSA-qxg6-89mg-rqv8), [Tinypool worker options](https://github.com/advisories/GHSA-5gmw-xhrv-c9v3), [Vite custom middleware](https://github.com/advisories/GHSA-9jrq-w75r-8gcw), [happy-dom untrusted HTML](https://github.com/advisories/GHSA-c8p4-j97h-3vg8). ## Licensing sources and interpretation

- [GNU GPLv3 §13](https://www.gnu.org/licenses/gpl.en.html#section13): confirms GPLv3/AGPLv3 combination permission, preserving GPL terms on GPL portions and applying AGPL network requirements to combination. This is not blanket relicensing of GPL files.
- [GNU AGPLv3](https://www.gnu.org/licenses/agpl-3.0.html): remote retrieval timed out; full text was inspected in repository LICENSE (especially sections 4-6 and 13). Practical release recommendation is a prominent link to exact corresponding source and preserved notices.
- [Official DCSS repository](https://github.com/crawl/crawl): README explicitly GPLv2+; full [LICENSE](https://raw.githubusercontent.com/crawl/crawl/master/LICENSE) retrieved.
- [Official tile licensing project](https://github.com/crawl/tiles), [unclear-license exclusion list](https://github.com/crawl/tiles/blob/master/TILES_UNDER_UNKNOWN_LICENSE.md), [DCSS tile submission rules](https://github.com/crawl/crawl/blob/master/crawl-ref/docs/develop/tiles_creation.txt): many tiles CC0, but verify specific assets. Do not infer all tiles are CC0 from submission defaults.
- Super Dungeon Crawl supplied GitHub URL and raw LICENSE fetches failed; no license compatibility conclusion asserted. No import is required for this project.

## Completed, unresolved, recommendation

Completed independent source inspection of loader/proxy/credentials/socket/session, safe local reproductions of global execution/private-destination acceptance/malformed message error, audit triage, primary-source license check and attribution inventory review. No physical controller, real login, public-server gameplay, deployed Worker network policy, or full dependency exploit tests performed.

Recommend full fork with security hardening as Phase 1 gates and a narrowly scoped authoritative-client architecture. Disagree with any claim that official-client use of AMD evaluation makes this safe: official client normally shares a server's own origin; Orbrun combines multiple servers' tokens in one origin. Disagree that a filename allowlist alone removes proxy value to attackers. Reject a renderer rewrite as a prerequisite to security fixes. No justified need for Canvas/Pixi/Three all as permanently supported primary backends; keep existing renderer for baseline, select future rendering technology on measured needs.
