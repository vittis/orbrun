# Release 0.3.105 — Distinct and stronger elemental splatters

Source version **0.3.105**, immutable source tag **`cloudflare-online-v1.102`**. The implementation is commit `904ad3d`. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md) through the automatic main-triggered Workers Build, retaining production main through `de6964c` and all earlier agents’ RC-editor, critical-health and spell-coverage work. A fresh-main guard and atomic non-force push protect intervening releases.

Electrical hit/death particles now use two jagged, forked lightning masks with blue edges and white cores. Larger major discharges reroute and pulse briefly using effect age, remain airborne and dissipate quickly. Other refinements distinguish rising fire tongues, icy shards/crystals, bubbling poison/vapour, elongated acid spits and luminous purple magic glints. Elemental particles have more size and density at the existing settings. Whole-burst variation stays deterministic across redraws.

Dense bursts reserve room for the elemental signature within the existing 96-particle hit and 192-particle death limits. Death floor splatter is retained when airborne debris needs trimming. Existing body material, gore/variation preferences, confirmed contact, visibility/occlusion, native-art ownership, Still/reduced motion, lifecycle cleanup and production’s online-only boundary remain supported. This release also retains the Fulminant Prism/Mystic Blast and broader spell/ability coverage from 0.3.104.
