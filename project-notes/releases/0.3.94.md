# Release 0.3.94 — Keep quick-settings focus in the controls

Source version **0.3.94**, immutable source tag **`cloudflare-online-v1.91`**. Includes the complete left-center Tune panel from [0.3.93](0.3.93.md) and all concurrent releases through 0.3.92.

Linux Chromium blurs a button when it becomes disabled; the local Mac browser retained focus. Consequently Reset could leave keyboard focus outside the quick panel. Refresh now explicitly focuses the active View/Combat tab if a previously focused control becomes disabled or loses focus during the update. This covers Reset, numeric bounds and disabled dependencies. The regression requires the actual active tab to receive focus rather than merely checking containment.
