# Release 0.3.81 — Continuous character animation

Source version **0.3.81**, immutable source tag **`cloudflare-online-v1.78`**. Publication uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Flying, breathing, swaying and wounded poses keep their phase across confirmed steps, rapid turns and mutable artwork updates. Each tracked actor retains its initial phase origin and an integrated animation clock, so health/haste rate changes alter pace without multiplying elapsed session time into a new phase. Subpixel hover offsets and filtered enlarged sprite pixels remove the rounded hover staircase. Identity matching, visibility, confirmed movement/camera curves and Still/reduced motion remain intact.

Feature commit `6aa4a20` was merged with concurrent main `62fa067` through `106b935`. The renderer conflict was resolved by retaining restored spell atmosphere, cloud opacity/filtering, spell-terrain fixes and wider death splatter together with continuous actor poses. Other worktrees were not changed. Publication uses an atomic, non-forced main/tag push.
