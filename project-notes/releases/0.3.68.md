Source version **0.3.68**, immutable source tag **`cloudflare-online-v1.65`**. The release follows the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Source publication/automatic build status is available from the [immutable tag](https://github.com/vittis/orbrun/tree/cloudflare-online-v1.65) and [verification workflow](https://github.com/vittis/orbrun/actions/workflows/verify.yml). This keeps the source tag immutable and avoids a duplicate main deployment merely to record its result.

Physical controllers/phones, authenticated play, optional engine execution and broader browser/server compatibility remain explicit limits. The short-window map area is necessarily small.
