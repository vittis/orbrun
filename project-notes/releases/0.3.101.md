# Release 0.3.101 — Elemental hit and death splatters

Source version **0.3.101**, immutable source tag **`cloudflare-online-v1.98`**. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md) through the automatic main-triggered Workers Build.

Confirmed hit elements now add fire embers, cold/electric shards, poison/acid droplets or magic wisps alongside the existing creature material. Deaths retain same-turn hit evidence briefly across frames, expire older evidence and preserve visible attacker direction. Creature names do not recolor physical attacks. Misses, shield blocks, zero-damage results and utility/status cues do not shed damaging-hit debris.

Combat settings expose VFX variation from Off to 100%, defaulting to 25%. Each spawn has a deterministic profile for count, energy, size and spray shape; redraw cadence does not reseed particles. Existing gore and direction controls remain independent. Defaults match the requested baseline: bump strength 175%, speed 115%, snap 70%, hit/death gore 100%/50%, and hit/death outward spray 100%/75%. Saved overrides, visibility clipping, particle caps, death ownership and Still/reduced motion remain supported.
