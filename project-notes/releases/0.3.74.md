# Release 0.3.74 — Native spell tile transitions

Source version **0.3.74**, immutable source tag **`cloudflare-online-v1.71`**. Uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Corrects 0.3.72's overly elaborate spell entrances. Removes the added spawn particle artwork and all entrance scaling/stretching. Native sprites keep their geometry, colour and placement; only opacity changes over a 100 ms entrance and 80 ms exit. Flame Wave's cell anchoring is preserved. Brief overlays received and cleared between frames get a minimum 60 ms exposure. Retiring visuals do not supply hit regions or badges, and visibility/Still/level changes clear their histories.

Preserves main `b4030f5`, including the latest melee clipping and auxiliary-attack fixes. Adds native pixel-footprint and colour checks, departure lifecycle checks and upright/flat terrain coverage. No sprite files or atlas assets were edited.

Verification passed: `npm run verify` (2,282 unit tests; two optional-engine skips), the full renderer/interaction suite, and the complete release gate (forced TypeScript, **2,297 unit/deployment tests**, two optional-engine skips, production build and **16 Chromium checks**). The browser suite includes 4,648 existing raster assertions, 80 native-transition assertions and 12 atmosphere assertions. A temporary Playwright config retained strict loopback servers and moved only the occupied development port from 5286 to 5296; production preview used 5287.

Reviewed the final integrated diff, including the removed burst renderer and transforms, snapshot/fade lifetimes, native terrain layering and release source links. Hosted deployment is verified; evidence follows below. Authenticated play, physical devices, optional engine execution and live casting of the affected spells are outside this acceptance.
