# Release 0.3.74 — Native spell tile transitions

Source version **0.3.74**, immutable source tag **`cloudflare-online-v1.71`**. Uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Native sprites keep their geometry, colour and placement; only opacity changes over a 100 ms entrance and 80 ms exit. Flame Wave's cell anchoring is preserved. Brief overlays received and cleared between frames get a minimum 60 ms exposure. Retiring visuals do not supply hit regions or badges, and visibility/Still/level changes clear their histories.
