# Release 0.3.112 — Unexplored dungeon atmosphere

Source version **0.3.112**, immutable source tag **`cloudflare-online-v1.109`**. Fog implementation `17d8953` includes current main's snapshot-clock fix `650732e`. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md): fresh-main guards, atomic non-force main/tag publication and the main-triggered Workers Build.

Soft slate-blue mist and sparse dust motes drift behind unexplored terrain. View → Unexplored fog is enabled by default and persists independently of animation preferences. Still/reduced motion freezes the effect. Known ground and standing geometry occlude it; hidden terrain, actors and map bounds never supply its appearance. Remote levels and fully explored viewports do not gain an ambient animation loop. Flat supporting maps retain their existing rendering.
