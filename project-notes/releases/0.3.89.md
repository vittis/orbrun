# Release 0.3.89 — Wider Dungeon camera ranges

Source version **0.3.89**, immutable source tag **`cloudflare-online-v1.86`**. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md) through the automatic main-triggered Workers Build.

Dungeon tilt now spans **25°–85°** in 5° steps, and zoom spans **25%–300%** in 5% steps. Settings, persistence validation and renderer clamps agree, so the new choices take effect. Defaults, stored custom values, Still/reduced motion, supporting flat maps and server-authoritative gameplay remain unchanged.

The 25° lower bound retains clickable narrow-corridor floors. An initial 15° candidate failed that existing invariant because the foreground lip obscured part of the floor; it was rejected before publication. Rendering checks cover all four new tilt/zoom endpoint combinations on narrow and desktop canvases, including projected scale, pixels, picking and Still mode.

Integrated concurrent release `1e8905c` (0.3.88), preserving its shorter mutual bumps and fine combat controls. No other worktrees or servers were modified. The previous release's evidence-only follow-up is also retained.
