# Release 0.3.72 — Spell entrances and anchored explosions

Source version **0.3.72**, immutable source tag **`cloudflare-online-v1.69`**. Uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Short, material-specific blooms introduce confirmed Ice Thorns terrain, Fulminant Prism and similar constructs, clouds and stationary spell overlays. Generic area explosions retain their server cells rather than joining nearby overlays into projectile paths. Dedicated projectile artwork keeps its existing travel, including bent lightning paths. Entrance effects do not replay on initial views, visibility reveals or charge variants, and clear for Still/reduced motion, remote maps and level changes.

Integrated main `fd49071`, preserving the newer melee artwork and motion changes. Integration completed without conflicts. The release adds 32 deterministic browser raster assertions for entrance visibility, settling, animation sleep, Still and hidden-cell cleanup at desktop and narrow/DPR sizes.

The complete release gate passed: forced TypeScript, **2,293 tests** including the real-Git deployment suite, two optional-engine skips, production build and **15 Chromium checks**. Browser acceptance includes the full 4,072 existing raster assertions, 32 new spawn assertions, 12 atmosphere assertions, real input/map lifecycle/reduced motion and production's online-only shell. The gate used its standard commands with a temporary Playwright config changing only the development server to strict loopback port 5296; port 5286 was occupied by another checkout. Production preview retained strict port 5287.

Reviewed the integrated diff against current main, including effect ownership, stationary overlays, preserved projectile paths, lifecycle cleanup, source links and release metadata. Hosted deployment is verified; evidence follows below. Physical devices, authenticated play and optional engine execution remain outside this release's acceptance.
