# Release 0.3.71 — Stronger melee artwork and consistent motion

Source version **0.3.71**, immutable source tag **`cloudflare-online-v1.68`**. Uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Nine weapon families receive hand-authored, outlined pixel artwork, solid strike opacity and thicker trails. Whips use a continuous braided body. One shared guard and cubic path replace mixed origins and phase jumps; attack heading is captured once so moving targets do not rotate the weapon. Preview timeline scrubbing and motion guides expose the paths in all directions.

Current main `34a786c` is preserved as an ancestor, together with the previous release's deployment evidence. Integration required no conflicts, resets or force pushes.

Integrated `npm run verify:release` passed: forced TypeScript, **2,283 tests** (including the real-Git deployment suite), two optional-engine skips, production build and **14 Chromium checks**, including the full 4,072 raster assertions and 12 atmosphere assertions. Reviewed the integrated renderer, authored artwork, common guard, fixed heading, opacity, miss clearance and preview changes against current main. Hosted evidence is recorded below and on the release branch without changing the immutable source tag or triggering a duplicate deployment.

Physical devices, authenticated play and optional engine execution remain outside these checks.
