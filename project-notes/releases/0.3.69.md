# Release 0.3.69 — Fast iteration and combat popup removal

Source version **0.3.69**, immutable source tag **`cloudflare-online-v1.66`**. Follow [DEPLOYMENT.md](../DEPLOYMENT.md) for the main-triggered Workers Builds release path.

This release removes floating combat text, its setting, assets, testbed overlays and dedicated engine patches. Confirmed world combat, spell/healing/status and death effects remain. Existing 2.5D renderer algorithms and artwork are preserved.

Everyday verification now uses incremental TypeScript and retained unit tests. Local measurements show about 85% less waiting for the ordinary completion gate and about 80% less browser test time with the representative smoke profile. Full rendering and production acceptance remain in the release gate. [BASELINE.md](../BASELINE.md) records measurements and coverage tradeoffs; [AGENTS.md](../../AGENTS.md) and [RUNBOOK.md](../RUNBOOK.md) explain which checks to run.

Local `npm run verify:release` passed: forced TypeScript; **2,237 tests** (2,222 unit plus 15 real-Git deployment tests), two optional-engine skips; one production build; **14 Chromium tests**, including all **4,072 raster assertions** and 12 atmosphere assertions. [Browser report](0.3.69/browser.json). Integrated diff review confirmed the renderer/artwork trees are unchanged, full release matrices remain intact, and popup references remain only in historical records and the legacy-settings migration regression. Final source/build/deployment identities and hosted evidence are recorded below and in the [published release record](https://github.com/vittis/orbrun/blob/codex/baseline-stabilization/project-notes/releases/0.3.69.md). This keeps the source tag immutable and avoids a second deployment solely to record its result.

Optional engine artifacts are absent: the removed patches have not been tested in a rebuilt WASM engine. Physical devices, authenticated play and broader browser/server acceptance remain outside this release's checks.
