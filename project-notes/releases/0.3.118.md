# Release 0.3.118 — Soft stars and an independent atmosphere toggle

Source version **0.3.118**, immutable source tag **`cloudflare-online-v1.115`**. Implementation `0e67d85` refines the uniform starfield and separates its decorations from exploration transitions. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md): fresh-main guards, atomic non-force main/tag publication and the main-triggered Workers Build.

Stars use cached circular falloff with stable differences in size, tone and brightness, gentle curved drift and restrained light variation. A handful of faint tapered curls rotate slowly in the black background. These decorations remain independent of branch and hidden terrain and fade away near confirmed geometry. View → Unexplored atmosphere removes stars and curls while preserving the same soft exploration frontier. Its boolean preference persists separately from the existing master fog setting. Still/reduced motion freezes presentation; supporting maps and confirmed actors remain unchanged.
