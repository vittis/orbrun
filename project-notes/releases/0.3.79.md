# Release 0.3.79 — Stable terrain beneath spell effects

Source version **0.3.79**, immutable source tag **`cloudflare-online-v1.76`**. Uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Crawl's explosion screen glyph is `#`. The scene adapter previously treated that glyph on floor-range artwork as a vault wall, briefly extruding floors and changing connected-wall cutaways before native explosion artwork appeared. The same glyph-dependent fallback could flatten transparent/decorative walls when another glyph covered them. Wall promotion now uses the server's `MF_WALL` / `MF_MAP_WALL` categories. Solid wall artwork and actual terrain updates remain authoritative. This applies to all effects sharing the glyph path, without a spell-name whitelist.

Restored the earlier spell lighting, atmospheric particles, cloud/construct motion, cloud opacity, surface tint, fading residues and contact-effect scale as requested. Kept native entry/exit fades, fixed area/cloud positions, duplicate area-burst suppression and the light-mask correction that prevents native overlays from posing as upright occluding actors. No sprite assets changed.

Integrated on `4bb62e6`, preserving the other agent's 0.3.78 removal of weapon VFX and retained body bumps. This release does not restore removed weapon artwork or controls.
