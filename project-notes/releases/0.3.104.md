# Release 0.3.104 — Spell and ability splatter coverage

Source version **0.3.104**, immutable source tag **`cloudflare-online-v1.101`**. The implementation is commit `e74e1ab`; publication follows [DEPLOYMENT.md](../DEPLOYMENT.md) through the automatic main-triggered Workers Build. This release includes production main through `d4b4ae4`, preserving the RC editor and critical-health vignette releases. Publication uses a fresh main check and an atomic, non-force push; newer concurrent work must be integrated rather than replaced.

Fulminant Prism’s energy explosion and Iskenderun’s Mystic Blast now retain magic colour in the existing hit and death splatters. Coverage also includes Searing Ray, Force Lance, Battlesphere, Orb of Destruction, energy/shadow attacks, Mindburst and Dispel Undead. Missing elemental result wording includes Hailstorm, creeping frost, Toxic Bog, caustic explosions, plasma and Blinkbolt. Explicit elemental outcomes of chaos beams retain the reported element. A separate spell result no longer loses its element when a melee hit shares its recipient and turn.

Classification follows explicit damage results, before creature melee grammar, with complete effect-name matches. Cast messages, spell selection, misses, status-only cues, zero-damage results, hidden recipients and Still/reduced motion do not create damaging splatter. Existing visibility, death ownership, particle bounds and settings remain unchanged.

Audited the stable and trunk native spell messages against Crawl’s [zap definitions](https://github.com/crawl/crawl/blob/stone_soup-0.34/crawl-ref/source/zap-data.h), [explosion setup](https://github.com/crawl/crawl/blob/stone_soup-0.34/crawl-ref/source/mon-explode.cc), [beam result handling](https://github.com/crawl/crawl/blob/stone_soup-0.34/crawl-ref/source/beam.cc) and [direct damage spells](https://github.com/crawl/crawl/blob/stone_soup-0.34/crawl-ref/source/spl-damage.cc). Native names identify the result; a creature’s elemental name does not recolor its physical attacks.
