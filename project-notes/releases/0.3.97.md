# Release 0.3.97 — Stacking shield, dodge and armor popups

Source version **0.3.97**, immutable source tag **`cloudflare-online-v1.94`**. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md) through the automatic main-triggered Workers Build.

Confirmed shield blocks use the gold shield symbol. Explicit zero-damage hits use a steel breastplate, and misses use a sidestepping figure with passing whiff marks. Projectile shield blocks also produce feedback without inventing a melee lunge.

Every confirmed attempt receives its own popup, including repeated outcomes in one turn. Defensive popups no longer suppress one another or a damaging hit's blood/material spray. Stable slots keep surviving symbols in place; histories retain up to six popups per recipient and 24 globally. Each popup springs upward with a short overshoot and squash/settle, then lifts and smoothly fades over a 720 ms lifetime. Symbols draw above scenery and world exposure while preserving visible-recipient ownership, death/removal/level cleanup and Still/reduced motion.

Integrated **`72f71af` / 0.3.95** (shield-blocked melee and prior quick-settings releases) and **`41936bb` / 0.3.96** (identical-enemy attack attribution). The architecture-note conflict was resolved by retaining both explanations. Concurrent source and tests remain intact; no other worktree or server was modified. Feature commit: `3e8efbe`.
