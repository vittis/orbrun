# Release 0.3.114 — Floor-supported scenery

Source version **0.3.114**, immutable source tag **`cloudflare-online-v1.111`**. Implementation commit `69c1d9d` follows the current 0.3.113 release, preserving the concurrent UI polish, fog and level-up work. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md): fresh-main guards, atomic non-force publication of main and its source tag, and the main-triggered Workers Build.

Ruined columns and related freestanding terrain artwork use their authored silhouettes and the existing soft ground shadows instead of an extruded square wall base. The scene builder recognizes columns, statues, idols, gravestones, shrines and related prop families even when their server minimap category is wall. Actual masonry remains raised. The change affects presentation; the server continues to own terrain, movement and visibility.
