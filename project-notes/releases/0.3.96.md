# Release 0.3.96 — Attack bumps for identical enemies

Source version **0.3.96**, immutable source tag **`cloudflare-online-v1.93`**. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md) through automatic Workers Builds.

The prior source matcher discarded every creature melee bump whenever several visible in-range attackers had the same name. In the reported four-enemy surround, the orc and goblin animated but both hobgoblins remained still despite confirmed attacks.

Each confirmed attempt now selects the least-used visible, name-matched source in that server turn, with stable actor identity breaking ties. Allocation survives messages arriving across rendered frames and resets on turn/level/session changes. Hidden and out-of-reach sources remain excluded; ambiguous creature recipients remain excluded from source allocation. Storage is bounded and departed actors are pruned.

Native attack messages omit attacker IDs, so attribution among otherwise identical sources is a deterministic presentation fallback, not an assertion of exact server identity. There is one animation per reported attempt, without fanning out a message to every candidate or multiplying its damage/results. Authoritative cells, HP, visibility, miss/block/no-damage behavior, Still/reduced motion and the online-only boundary remain unchanged.

## Validation

- New regressions reproduce the original bug before the fix: the four-enemy fixture produced only two bumps for hit, miss, block and zero-damage cases. After the fix, all four attackers animate.
- Focused combat units: **131 passed**. Coverage includes cross-frame appended packets, rollback deduplication, deterministic composition order, per-turn/level reset, reach/visibility and ambiguous recipients.
- Chromium renderer integration confirmed all four actors visibly lunge at contact (approximately 10 screen pixels each), then return to their original projected cells. No page errors. Evidence is under ignored `test-results/identical-enemies-*`.
- `npm run verify`: incremental TypeScript and **2,325 unit tests passed**, with two optional-engine skips.
- `npm run verify:release`: forced TypeScript, **2,340 unit/deployment tests**, production build and **20 Chromium tests passed**, with two optional-engine skips and zero retries. Includes the full rendering matrix, interaction checks and production preview.
- Reviewed the integrated diff and immutable source links. A guarded clean-tree dry-run precedes the atomic non-forced main/tag push. Hosted source/bundle checks and the observed automatic deployment result are reported after publication.

Optional engine artifacts, authenticated play and physical-device acceptance remain outside these checks. Concurrent main changes are integrated before publication; no other checkout or server is modified.
