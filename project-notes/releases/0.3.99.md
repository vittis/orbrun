# Release 0.3.99 — Quieter shield and armor feedback

Source version **0.3.99**, immutable source tag **`cloudflare-online-v1.96`**. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md) through the automatic main-triggered Workers Build.

Miss/dodge VFX are removed from combat scheduling, the renderer effect type and impact artwork. Confirmed attack bumps remain. Shields emit three short horizontal golden ricochets in a sideways fan; zero-damage armor impacts emit five compact steel chips that scatter and fall. Reduced particle counts and travel keep both effects quieter, while their shape and motion distinguish them without relying on color alone.

Shield and armor bursts still accumulate independently alongside blood, retaining smooth expansion/settling/fade, bounded histories, confirmed visibility, actor removal, death cleanup, Still and reduced motion. This release builds on 0.3.98; main was unchanged during preparation and no other worktree or server was modified.
