# Release 0.3.93 — Quick View and Combat controls

Source version **0.3.93**, immutable source tag **`cloudflare-online-v1.90`**. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md) through automatic Workers Builds.

The game and spectator screen now have a **Tune** button anchored at the left-center. It opens a non-modal panel with View and Combat tabs containing every setting in those groups. Numeric controls combine sliders with small decrement/increment buttons; other settings use selectors. Changes apply immediately through the existing settings path, persist in the same storage and refresh disabled controls across both groups. Reset affects only the selected group. Numeric buttons stop at their bounds.

The panel fits and scrolls within the game viewport, including phone and short-window layouts. Native keyboard controls and focused controller navigation do not send gameplay commands. Escape or Android Back closes it, pending gamepad holds are disarmed while controls have focus, and clicking the dungeon returns focus to gameplay. Full settings changes refresh the panel. Temporary flat maps retain their renderer and receive updated dungeon preferences when restored.

Integrated concurrent releases **0.3.90**, **0.3.91** and **`2007533` / 0.3.92**, preserving raised side walls and the latest miss/zero-damage symbols. The deployment guard rejected the stale 0.3.92 quick-settings candidate before upload; its version was advanced without moving or reusing a source tag. No other worktrees or their servers were modified.
