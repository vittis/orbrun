# Release 0.3.70 — Weapon-specific melee gestures

Source version **0.3.70**, immutable source tag **`cloudflare-online-v1.67`**. Uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Nine melee families now have distinct pixel-art silhouettes and timing: long blades, short blades, spears/tridents, axes, bladed polearms, maces/clubs, whips, staves and unarmed. Upright hammer/axe/fist shapes replace rotating heads. New Combat settings tune effects, weight, trails and lunge/recoil. The development preview covers 27 gestures, directions, reach, misses and elemental tones.

Integrated current main at `070f829`, preserving 0.3.69's removal of combat popups, assets and engine patches and the revised verification workflow. Four overlapping settings/test files were resolved explicitly; no other worktrees or commits were reset or overwritten.

Integrated `npm run verify:release` passed: forced TypeScript, **2,277 tests** (including the real-Git deployment suite), two optional-engine skips, production build and **14 Chromium checks** covering the full 4,072 raster assertions and 12 atmosphere assertions. Reviewed the integrated diff against current main, including settings migrations, contact/miss alignment, Still behavior and the preserved popup removal. Final hosted identity and automatic build evidence will be appended on the [release branch](https://github.com/vittis/orbrun/blob/codex/melee-weapon-rework/project-notes/releases/0.3.70.md) after deployment, without moving the immutable tag or causing a second main deployment.

Physical devices, authenticated play and optional engine execution remain outside these checks.
