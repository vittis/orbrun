# Release 0.3.87 — Finer Dungeon view controls

Source version **0.3.87**, immutable source tag **`cloudflare-online-v1.84`**. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md) through the main-triggered Workers Build.

View settings now offer Dungeon tilt from 35° to 65° in 5° steps and Dungeon zoom from 80% to 140% in 5% steps. The existing mouse, keyboard, touch and gamepad adjustment paths share these choices. Defaults, custom saved values, reset behavior, Still/reduced motion and supporting flat maps are preserved.

Based on `7022d75` (0.3.86), preserving the preceding shared melee bumps and all earlier releases. No other worktrees or running servers were modified. Publication checks fresh remote ancestry and uses an atomic, non-forced main/tag push.
