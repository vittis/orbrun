# Release 0.3.122 — Polished Crawl menu

Source version **0.3.122**, immutable source tag **`cloudflare-online-v1.119`**.
The [source tag](https://github.com/vittis/orbrun/tree/cloudflare-online-v1.119)
identifies the release commit. This release includes production main through
`4a2be31` and the approved design handoff imported as `30bd536`.

The responsive home now has compact server/authentication controls, stable
server-derived Play/Continue rows with separate RC actions, and shared accessible
About/news modals. Local licensed fonts and a restrained title reflection match
the approved design. Existing account management, registration, recovery,
news-read storage and gameplay remain compatible. Descent is omitted at the
home presentation boundary; protocol game-link handling remains shared.

A finished silent VP9 clip (1280×720, 23.88 seconds, approximately 2.3 MB) and
poster replace the live menu room. The local recorded-fixture capture observed
seven confirmed combat impacts. [Media provenance and capture recipe](../../apps/orbrun/public/menu/README.md)
record the source, licensing limitations and reproducible tooling. Still and OS
reduced motion suppress decorative work; hidden/covered menus pause playback,
and teardown releases media/listeners. The old room owner, splash, drag styling,
separate news screen and their obsolete tests were removed. Renderer fixtures
and static-document assets with remaining consumers were retained.

## Validation and publication

`npm run verify:release` passed: forced TypeScript, **2,540 unit/deployment tests**,
one production build and **41 full raster/interaction/production browser tests**,
with zero retries. Two optional-engine tests skipped because the engine artifacts
are not provisioned. The existing large-bundle build warning remains non-fatal.
Desktop and narrow touch screenshots and the finished clip were inspected.

Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md): clean-tree/current-main
guards, guarded dry-run, atomic non-force main/tag push, then the main-triggered
Workers Build. Hosted source, assets and deployment identity must be observed
before reporting success. No authenticated-play, physical-device or optional-engine
acceptance is claimed from local fixtures. Deployment evidence is reported with
the completed release rather than predicted in this immutable source record.
