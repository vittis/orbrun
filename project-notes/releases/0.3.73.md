# Release 0.3.73 — Unclipped melee and minotaur follow-ups

Source version **0.3.73**, immutable source tag **`cloudflare-online-v1.70`**. Uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

The dungeon renderer no longer scissors upright melee artwork to visible floor-cell rectangles. Both attack endpoints must still be visible at acceptance and throughout the effect; weapon overhang does not reveal terrain. Real Canvas comparisons reproduced lost axe pixels in the published renderer, including entirely missing strokes, while the isolated preview retained them.

Explicit natural follow-ups such as minotaur headbutts retain confirmed damage feedback without generating another swing of a wielded axe. Same-turn headbutts stay attached to the preceding melee target, including after a miss, while genuine cleaves continue to select separate same-name enemies. The melee testbed now includes the actual dungeon renderer and defaults to the game's 50-degree camera tilt.

Integrated newer main **`5053a5f`**, retaining 0.3.72 spell entrances and anchored explosions as well as earlier release evidence. The only merge conflict was in the browser test list; both the spawn test and new melee matrix were retained. No reset or force push was used.

Validation: `npm run verify` passed before integration (2,271 unit tests, two optional-engine skips). The new 64-case melee smoke matrix failed against the published renderer and passed with the fix. The final integrated `npm run verify:release` passed: forced TypeScript, **2,296 tests**, two optional-engine skips, production build and **16 Chromium checks**. It includes 576 new live-versus-isolated melee raster comparisons across eight directions, variants, camera tilts, hits and misses, plus all 4,072 existing raster, 32 spawn and 12 atmosphere assertions. The initial expanded matrix exposed an overly strict opaque-pixel threshold for tiny scaled artwork; the coverage oracle now includes partially covered bright pixels and the full matrix passes.

Reviewed the integrated diff for clipping, visibility admission/lifecycle, headbutt identity and retained spell effects. Minotaur behavior was reproduced through confirmed combat-message fixtures; no player's character was controlled. Physical devices, authenticated play and optional engine execution were not tested. Hosted identity and deployment evidence will be appended on the release branch after publication without moving the immutable source tag or triggering another deployment.
