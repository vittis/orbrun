# Release 0.3.77 — Subtle native spell transitions

Source version **0.3.77**, immutable source tag **`cloudflare-online-v1.74`**. Uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Native spell tiles retain their artwork, server variants, confirmed cells and short opacity-only entrances/exits. No atlas or sprite assets changed. Removed stacked spell light pools, atmospheric particles and lingering cloud residue; cloud/construct silhouettes no longer receive procedural deformation or extra surface tint. Clouds stay at confirmed cells instead of being matched into movement tweens.

Spell overlays no longer add upright headroom to environmental lighting masks. This prevents surrounding floor/wall shading from changing simply because an explosion/cloud appears. Existing environmental lights remain. Area effects own their native art without a second generated burst; ordinary missile contact and spells without native art retain a smaller cue. Confirmed hit spray, damage feedback, visibility, Still/reduced motion and server timing remain intact.

Integrated on `9830a47`, preserving the concurrent player-only melee, configurable hit bumps and organic hit-splash releases. Publication refetches remote main and uses an atomic, non-forced commit/tag push.

## Validation

- Focused effect/renderer/recorded-session tests passed. Initial broad checks exposed old expectations for cloud afterglows/idle deformation and overly broad suppression of moving-missile contact. Updated cloud expectations and restricted burst suppression to native area artwork; retained all recorded missile timing/contact regressions.
- Full release gate passed: forced TypeScript, **2,306 unit/deployment tests**, **two optional-engine skips**, production build and **16 Chromium checks**. Used the same gate stages with a temporary Playwright config on strict dev port 5296 (production preview 5287) to avoid another checkout's occupied default port. No retries.
- Full renderer/interaction gate also passed (15 Chromium checks); the final release gate includes the final edits. **4,648 raster assertions**, **274 spell assertions**, and **12 atmosphere assertions**. Sixteen spell-art families cover terrain, constructs, cold/fire/poison/acid/storm clouds, Blastmotes, generic explosions, Fire Storm and Iceblast. Independent shape/colour references plus exact pixel comparisons outside native footprints protect nearby patterned floors, raised walls and torch masks.
- Reviewed the actual diff and captured desktop/narrow synthetic spell fixtures. These deterministic fixtures exercise shared rendering paths; they do not constitute authenticated casting of every spell. Physical devices, authenticated gameplay and optional engine execution remain outside acceptance.

Hosted identity, build/deployment identifiers and anonymous production checks will be recorded after publication without moving the immutable source tag or triggering a duplicate deployment.
