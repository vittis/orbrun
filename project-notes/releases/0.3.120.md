# Release 0.3.120 — OSP sound effects

Source version **0.3.120**, immutable source tag **`cloudflare-online-v1.117`**.
This release builds on `0a50f5b` (0.3.119). Publication follows
[DEPLOYMENT.md](../DEPLOYMENT.md): clean-tree/current-main guards, atomic
non-force publication of main and the source tag, and the main-triggered
Workers Build. The [source tag](https://github.com/vittis/orbrun/tree/cloudflare-online-v1.117)
identifies the release commit; its GitHub checks identify the associated build.

Settings → Audio enables optional OSP sound effects, master/effects volume,
single or layered playback, explicit OSP download, local ZIP import, test sound,
cache refresh and removal. Archives are content-identified in a separate
IndexedDB database. Audio preferences stay local and are excluded from telemetry.
Music and positional audio are deferred.

Shared message occurrence tracking suppresses join history and old rollback
prefixes while preserving distinct repeated attacks. Worker-isolated ZIP and
regex processing, bounded queues/caches/voices, stale-result cancellation,
background suspension and session teardown preserve input and rendering.
Production remains online-only, with confirmed state/visibility and independent
Still/reduced-motion behavior.

## Validation

Implementation acceptance passed incremental TypeScript and 2,510 unit tests;
the full release suite passed forced TypeScript, 2,525 unit/deployment tests,
one production build and 36 browser/production tests with zero retries. Two
optional-engine cases skipped because their artifacts are not provisioned.
The final 0.3.120 release gate repeated these results after updating the version,
changelog and immutable source links.

Browser acceptance covers ZIP loading, real decoding/source playback, volume
persistence, IndexedDB restoration/removal, local import, live message rollback,
screen teardown and the shipped CSP. The automated pack is an authored WAV in a
synthetic ZIP and requires no public-server access. Manual Chromium validation
of the actual OSP archive `v261114145850` loaded 3,110 playable rules and 588
referenced sounds, reported 36 missing references, and started the hit sample
without page errors. Its SHA-256 is
`16f384b0f7d78782ebb7acf580d6d4904c56d9fde84d8a814fbc4bb833d23c6a`.

The existing large-chunk build warning remains non-fatal. No authenticated-play,
physical audio-device or engine acceptance is claimed. Hosted version/source,
bundle identity and Audio controls must be verified after Workers Builds
completes; a push alone is not deployment acceptance.
