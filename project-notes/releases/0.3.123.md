# 0.3.123 — Live menu encounters

Source tag: `cloudflare-online-v1.120`.

The menu now runs pinned DCSS 0.34.1 in a disposable worker, with a small authored
Sprint room and randomized encounters. Its reducer, visibility, normal 2.5D
renderer and confirmed combat presentation are shared with gameplay. Native
Crawl autofight advances one command per idle acknowledgement. No GameScreen,
account/session, input listener, sound pack or persistent filesystem is created.
Still/reduced motion releases the demo; covered/hidden menus park it. Failure or
missing JSPI support preserves a usable static poster. The recorded video and
capture-only tooling were removed.

The app packages only matching engine/gamedata artifacts at `/menu-engine/`;
`/engine/` and player-facing offline/custom-server play remain disabled. The
CSP permits Wasm compilation without enabling JavaScript unsafe-eval. Guarded
deployment provisions the pinned build tools and engine before packaging,
refusing missing/stale artifacts. See [menu provenance](../../apps/orbrun/public/menu/README.md).

Verification includes the full release gate (types, unit and real-Git deployment
tests, full raster matrix, interactions and production CSP), plus the separately
provisioned real engine suite. Browser evidence observes live combat, stopped
command/render clocks while covered and hidden, worker release/recreation for
reduced motion, and zero IndexedDB opens. Engine test infrastructure now follows
the commit-plus-recipe artifact path and checks the current dungeon/minimap
behavior. The optional trunk engine remains unprovisioned. No physical-device or
authenticated-player acceptance is claimed.

The initial pinned artifact set is about 43 MiB before HTTP compression. Local
Chromium's measured worker-start-to-first-map time was about 0.7–0.8 seconds;
this excludes the earlier gamedata load and is not a cold-network or physical
mobile-device performance claim.

Final local verification (Node 25.9.0 for JSPI, with native Node Web Storage
turned off so browser unit environments own their storage):

- `REQUIRE_MENU_ENGINE=1 npm run verify:release`: 2,550 tests passed, one optional
  trunk-engine test skipped; all 43 browser checks passed with zero retries.
- `REQUIRE_ENGINE=1 npm run e2e`: all 41 tests passed against the pinned build.
- The engine smoke test passed new-game, movement, save and resume checks.
- Final engine recipe: `be786e885d4ee655`; Crawl source remains the pinned commit
  above. Real-browser tests used the packaged production assets as well as dev.
