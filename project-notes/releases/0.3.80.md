# Release 0.3.80 — Wider death splatter

Source version **0.3.80**, immutable source tag **`cloudflare-online-v1.77`**. Publication uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

One third of death debris now launches around the body in jittered angular sectors, without the killing blow's directional push. The remaining particles preserve the forward fan. Higher launch energy, lower drag and a wider fan spread the effect farther while retaining particle counts, material artwork, lifetimes, visibility clipping and Still behavior.
