# Release 0.3.119 — Faster input and lower rendering overhead

Source version **0.3.119**, immutable source tag **`cloudflare-online-v1.116`**. Implementation `42ca21e` builds on `cfb1922` (0.3.118), retaining the existing fog, scenery, combat and UI work. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md): current-main guards, atomic non-force main/tag publication and the main-triggered Workers Build. Other worktrees and branches are left untouched.

Newly received prompts and menus are resolved before keyboard, controller and touch input, even between paints. Held repeats retain their cadence across uneven frames and discard missed beats after stalls. Movement matching indexes anonymous artwork instead of repeatedly scanning the entire actor list. Lighting culls unlit samples and reuses bounded scratch canvases; opaque fog pixels skip unnecessary noise calculations. Server authority, confirmed visibility/combat and Still/reduced motion remain intact.

[Runtime measurements](../BASELINE.md#runtime-responsiveness-pass--2026-11-14) and [sample data](../responsiveness-performance.json) record 23–27% lower median drawing time in local browser scenarios and a 625-item movement stress case reduced from 12.50 ms to 0.54 ms. Headless Chromium still showed late frames; these timings do not establish a locked frame rate or physical-device/server latency acceptance.

## Validation

- Development acceptance: incremental TypeScript, **2,496 unit tests** (two optional-engine skips), and **32 full browser tests** passed.
- Final `npm run verify:release`: forced TypeScript, **2,511 unit/deployment tests**, one production build, and **33 full browser/production tests** passed with zero retries; two optional-engine cases skipped.
- The immediate-input browser regression failed with the input refresh disabled and passed with it enabled. It also passes during animation and sends eight movement commands without an intervening paint.
- Added deterministic repeat/stall/release, stacked anonymous identity, light sampling/culling and cleanup coverage. Full raster checks retain fog, visibility, lighting, combat, map lifecycle and native reduced-motion behavior.

The existing non-fatal large-chunk build warning remains. No engine changes or authenticated/physical-device acceptance are claimed. Hosted source/version/bundle identity must match the release before deployment is reported successful; no manual deployment races Workers Builds.
