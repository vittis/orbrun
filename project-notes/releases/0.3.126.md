# 0.3.126 — Recorded gameplay menu

Source tag: `cloudflare-online-v1.123`.

The menu rotates through three curated real CDI spectator recordings: alchemy
in the Lair, ranged combat and ice magic with allies. Each retains the complete
preceding state and ordered map/player/combat messages, with idle gaps shortened.
The existing reducer, scene builder, 2.5D renderer and confirmed combat pipeline
render them. Clean state/presentation resets separate clips; messages are cloned
for repeatable loops. No WebTiles HTML, commands, chat or player identity is bundled.

Removed the menu worker/controller, Sprint scenario, pinned engine manifest,
artifact cache/provisioning/build scripts, Vite engine packaging and production
engine route exception. Development-only offline play remains. Production CSP
no longer permits Wasm evaluation; both engine routes return 404. Old menu asset
caches are removed without touching offline/account/save storage.

The three clips share one pinned artwork version. Their 7,316,542 bytes (6.98 MiB,
including all artwork, before HTTP compression) replace the prior 42.97 MiB menu
artifact set, about 84% less. Clip JSON totals 1,082,763 bytes, approximately 79 KiB
gzipped. Builds validate committed asset hashes; no engine toolchain or runtime
resource service is required. This is an asset comparison, not an FPS or physical
mobile-device benchmark.
