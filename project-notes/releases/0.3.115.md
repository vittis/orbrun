# Release 0.3.115 — Rolling branch atmosphere

Source version **0.3.115**, immutable source tag **`cloudflare-online-v1.112`**. Fog rework `46442cb` retains the concurrent UI release `d556949` and scenery release `1df76d9`. Publication follows [DEPLOYMENT.md](../DEPLOYMENT.md): fresh-main guards, atomic non-force main/tag publication and the main-triggered Workers Build.

Replaced faint circular fog stamps with a continuous, domain-warped cloud field. Layered smoke folds and opposing flow make movement perceptible within 1.5 seconds. A bounded, reusable low-resolution raster keeps work independent of pixel density and dungeon size. Known terrain and actors occlude the atmosphere; hidden cells, actors and map bounds never select its appearance.

The scene producer maps the server-reported branch to eleven generic moods. Dungeon/Depths/Vaults use blue-violet stone mist; Orc/Snake/Spider use earthy dust; Lair uses verdant mist; Swamp/Slime use marsh vapour; Shoals uses sea haze; Ice Cave/Cocytus use icy clouds; Hell/Gehenna/Volcano use sulphurous smoke; Crypt/Tomb/Tartarus use spectral mist; Elf/Zot use arcane fog; Abyss/Pandemonium use more turbulent purple clouds; Temple uses sacred haze. Color, flow, curl and shape vary by mood. Unknown/custom branches use the default. Existing preferences, Still/reduced motion, supporting flat maps, remote-level exclusion and fully explored viewport sleep behavior remain supported.

- **52 real-Canvas fog assertions** cover visible contrast, short-term motion, frame continuity, all eleven moods, Still, toggling, hidden terrain/actor independence, picking and idle viewports across narrow/desktop sizes, tilt extremes and multiple pixel densities.

- Earlier `npm run verify` passed **2,490 unit tests** and TypeScript; `npm run verify:render` passed **30 browser tests** before the final soft-shading refinement and concurrent scenery integration. The release gate above verifies the final integrated source.
- Chromium previews reviewed Dungeon, Lair, frost, volcanic and Abyss moods beside actual dungeon artwork, plus a recorded animation. Manual renderer measurements stayed outside the default suite; no wall-clock assertions were added.

The existing non-fatal large-chunk build warning remains. Optional engine artifacts, authenticated play and physical-device acceptance are outside this coverage.
