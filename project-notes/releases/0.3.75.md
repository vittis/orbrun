# Release 0.3.75 — Player-only melee and crunchy hit bumps

Source version **0.3.75**, immutable source tag **`cloudflare-online-v1.72`**. Uses the main-triggered Workers Builds path in [DEPLOYMENT.md](../DEPLOYMENT.md).

Only player attacks schedule melee weapon effects and lunges. Enemy damage still produces ordinary confirmed hit feedback. Each weapon family has one deterministic gesture; randomized variants and their preview controls are removed. Axes use a broad sweep in the common attack frame, thrusts use the centre line, and maces use a centred overhead blow. Misses shorten the same gesture instead of veering sideways.

Target recoil is stronger, reaches its peak quickly, holds briefly and settles. Combat settings add **Hit bump strength** (Off / 50% / 100% / 150%) and **Hit bump snap** (Soft / Firm / Crunchy). Defaults are 100% and Crunchy. Settings persist, reset with the Combat group, normalize unsupported values, and disable when movement/Still makes them unavailable. Motion stays bounded, starts only after confirmed contact, and never pauses input or changes authoritative cells.

Focused tests cover rejected enemy strokes, deterministic repeats, miss clearance, post-contact bump timing, strength/snap controls and settings persistence.
